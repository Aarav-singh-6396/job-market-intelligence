# 💼 Job Market Intelligence Dashboard

A professional interactive Job Market Intelligence Dashboard built using **Python, Pandas, and Streamlit** to analyze job-market data and provide insights into salaries, companies, locations, experience levels, job titles, and in-demand skills.

## 🚀 Features

- 📊 Interactive job market dashboard
- 🔎 Job search and filtering
- 💰 Salary analysis
- 🏢 Top hiring companies analysis
- 📍 Job opportunities by location
- 💼 Job title analysis
- 🎯 Experience-level analysis
- 📈 Advanced analytics and visualizations
- 📥 Filtered dataset download
- 📑 Job market reports
- ⭐ Saved jobs
- 🔔 Job alerts
- 🎨 Professional Streamlit UI

## 🛠️ Technologies Used

- Python
- Pandas
- Streamlit
- NumPy
- Matplotlib
- Data Analysis
- Data Visualization
- Excel / CSV
